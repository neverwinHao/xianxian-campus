# 建模迭代记录

以下记录概括项目在 2026-11-22 的实际建模过程。仓库从当前可运行版本整理而来，历史尝试以文档保存，没有伪造中间版本的 Git 提交。

| 阶段                | 工作与结果                                                                       |
| ------------------- | -------------------------------------------------------------------------------- |
| 体量搭建            | 依据公开地图和照片整理边界、道路与楼群关系，建立 JavaScript 参数化场景。         |
| 入口核对            | 按校名、拍摄位置和用户指认纠正门楼归属，分别构建南北校区入口。                   |
| 北校区航拍细化      | 加入蓝色坡顶、屋顶深色板、红白窗格、楼间连廊、院落和天文圆顶。                   |
| 南校区 reference-v7 | 按航拍和近照细化科技楼、教学楼银杏天井、亭子与后排楼体；移除运行时照片相册。     |
| 校区与食堂调整      | 展示范围收敛到北、南两个校区；北校区加入 A/B 部食堂并移除错误的运动场。          |
| 南校区宿舍对应      | 校门后为科技楼、教学楼，教学楼之后左右两栋宿舍，再往后是食堂和图书馆。           |
| 北校区入口景观      | 入门左侧是曲廊，右侧是银色雕塑；乔木统一使用绿色树冠。                           |
| 校服与步行          | 增加蓝白校服小人、关节动画、键盘、手机摇杆、边界和建筑碰撞。                     |
| 名称精简            | 页面只保留指定名称，模型与显示名单分开。                                         |
| 宿舍最终纠正        | A/B 部宿舍是连廊与教学楼连接的中排两栋；食堂后方楼体不再标注。打开页面自动漫游。 |
| 展示与发布          | 输出单文件页面、加入线上访问计数，并增加完整路线的视频录制工具。                 |

## 当前名称与布局

北校区显示：校门、左侧连廊、右侧雕塑、A部教学楼、B部教学楼、A部宿舍、B部宿舍、A部食堂、B部食堂。

南校区显示：校门、科技楼、操场、教学楼。南校区其他已建楼体仍然保留在场景中。

## 资料来源

- [学校官网](http://www.xxyzh.net/)：校名、公开学校资料和历史活动照片。
- [百度地图：南校区](https://map.baidu.com/search/河北省献县第一中学南校区)：校园轮廓、道路和入口定位参照。
- [百度地图：北校区](https://map.baidu.com/search/河北省献县第一中学北校区)：楼群相对位置参照。
- 用户提供的航拍、门楼、食堂、雕塑和校服照片，以及对建筑用途和前后关系的明确指认。

原始照片没有包含在此仓库中。程序只需要坐标参数、几何代码和本地 Three.js 库即可运行。尺寸、不可见立面和部分细部仍为近似，模型不提供测绘精度保证。
